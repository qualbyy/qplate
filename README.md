# скелетон рабочего стола

Личный сайт в виде рабочего стола с доком и окнами. Без сборки, библиотек и внешних шрифтов: несколько файлов логики и стилей, один файл с контентом. Внутри есть конструктор, который собирает готовый сайт в папку.

Открой `index.html` двойным кликом или запусти рядом любой статический сервер.

## что внутри

```
index.html   — пустая оболочка: место под окна и док
shell.css    — тема, окна, док, анимации, телефон
apps.css     — внутренности окон
data.js      — весь контент и список окон
apps.js      — поведение каждого типа окна
shell.js     — менеджер окон и дока
editor.css   — внешний вид конструктора
editor.js    — конструктор сайта
AGENTS.md    — памятка для ИИ-агентов и разработчиков
README.md    — эта шпаргалка
assets/      — локальные картинки для галереи и плеера
```

Девять готовых окон: терминал, заметки, браузер, файлы, фотографии, плеер, настройки, документ и конструктор.

## как сделать свой сайт

1. Скопируй папку целиком:

   ```
   cp -r ~/qplate ~/мой-сайт
   ```

2. Открой `data.js` и поменяй:
   - `meta` — имя, ник, заголовок страницы, подпись;
   - `windows` — какие окна есть в доке;
   - остальные разделы — тексты, ссылки, файлы, фото, треки, страницы документа.

3. Замени `assets/photo-*.svg` и `assets/cover.svg` своими картинками (можно оставить SVG или положить PNG/JPG и поправить пути в `data.js`).

4. Проверь сайт и выложи папку на любой статический хостинг.

## как добавить своё окно

Сначала добавь запись в `windows`:

```js
{
  id: "guestbook",
  type: "guestbook",
  title: "гостевая",
  label: "гостевая",
  icon: "gb",
  width: 480
}
```

Потом добавь отрисовщик в `apps.js` рядом с остальными:

```js
function renderGuestbook(body, cfg, ctx) {
  const app = document.createElement("div");
  app.className = "app-terminal";
  app.textContent = "здесь будет гостевая книга.";
  body.appendChild(app);
}

renderers.guestbook = { render: renderGuestbook };
```

Тип окна (`type`) должен совпадать с ключом в `APP_RENDERERS`. Если ключа нет, окно покажет аккуратную заглушку.

Отрисовщик получает:

- `body` — контейнер внутри окна, клади туда разметку;
- `cfg` — запись окна из `data.js`;
- `ctx` — небольшие функции: `open`, `close`, `minimize`, `center`, `focus`, `applySetting`, `getSettings`, `getWindow`.

Можно вернуть объект с хуками:

```js
return {
  onOpen: function () { /* окно открыли */ },
  onHide: function () { /* окно свернули или закрыли */ }
};
```

## настройки и внешний вид

- Цвета, шрифты, скругления — в начале `shell.css` в блоке `:root`.
- Ключевой цвет меняется в окне настроек: 6 пресетов из `data.theme.presets` плюс пипетка. Он перекрашивает акценты, фоны, границы и подложки по всему сайту, выбор запоминается в браузере.
- Тема: светлая, тёмная или как в системе. Тёмная строится из того же ключевого цвета, поэтому акцент остаётся узнаваемым.
- Обои рабочего стола: без обоев, точки, сетка, волны, бумага или своя картинка. Своя картинка выбирается кнопкой «выбрать файл», сжимается и хранится в браузере.
- Переключатели: анимации, подсказки дока, крупный текст, часы на столе, запоминание позиций окон. Всё это сохраняется в localStorage.
- Часы на столе показывают время и короткую дату; на телефоне и при выключенных часах скрываются.
- Позиции окон запоминаются, если включено «запоминать позиции», и не выходят за край экрана.
- Иконки приложений — SVG-строки в `data.icons`, в окне подключаются через `iconKey`.
- Скругление дока: `--dock-radius` (сейчас 20px), иконок: `--dock-icon-radius` (10px).
- На телефоне док сам уменьшается и прокручивается по горизонтали, а окна открываются по одному.
- Fastfetch в терминале собирается из `data.terminal`: `ascii`, `rows` и автоматически из `windows`. Команды — ключи `data.terminal.paths`.

## конструктор

В доке есть окно «конструктор» — это редактор содержимого прямо на сайте.

Что можно менять:

- проект: название сайта, имя пользователя, имя, подпись;
- заметки, документы и вкладки браузера — заголовок, текст или html, ссылки;
- фото: адрес картинки, название, подпись (кнопка «из файла» берёт картинку с устройства);
- музыка: альбом, обложка, треки;
- терминал: команды, их действие (текст, открыть окно, ссылка, свой javascript-код);
- настройки: какими будут тема, обои и переключатели в готовом сайте, какие цвета, темы и варианты обоев запретить, какие пункты убрать из окна настроек совсем;
- приложения: удалить лишнее, добавить свою страницу.

Кнопки вверху:

- **применить** — показать изменения на сайте (черновик хранится в браузере);
- **сохранить готовый сайт в папку** — собрать отдельный сайт: `index.html`, `data.js`, стили, скрипты, `README.md`, `project.json`. Нужны Chrome/Edge/Opera и запуск через сервер;
- **открыть проект** — загрузить `project.json`;
- **скачать файлы** — запасной вариант: скачивает `data.js` и `project.json`;
- **сбросить всё** (в разделе «проект») — вернуть исходные данные сайта и удалить черновик.

В собранный сайт конструктор не попадает: окно удаляется из `windows`,
а `editor.css` и `editor.js` не подключаются.

Подробная схема данных и правила правок — в `AGENTS.md`.

## как запустить

На компьютере:

```
git clone https://github.com/qualbyy/qplate.git
cd qplate
python3 -m http.server 8000
```

Если папка уже есть, хватит двух строк:

```
cd ~/qplate
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Можно и просто открыть `index.html`, потому что сайт не использует загрузку файлов через сеть.

## что упрощено намеренно

- Музыкальный плеер не проигрывает звук — только показывает прогресс.
- PDF-окно листает готовые страницы из `data.js` и скачивает текст в `.txt`, а не рендерит настоящий PDF.
- Кнопки «назад/вперёд» в браузере ходят по открытым вкладкам, а не по интернету.
- Внешние страницы не загружаются: браузер показывает разметку из `data.js`.
